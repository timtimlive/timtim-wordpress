# Security

**Please do not report security problems in public issues, discussions or pull requests.**

Report privately: open this repository's **Security** tab and press
**Report a vulnerability**. A person at TimTim.Live reads every report.

TimTim.Live's security policy, including what is in scope and how we
respond: https://timtim.live/partners/security

Supported version: the latest release offered at
https://timtim.live/partner-api/wordpress/ (the plugin updates itself from there).
